# 📚 SE NED Study Material Repository

This repository is created to provide a centralized and organized collection of academic resources for **Software Engineering students at NED University of Engineering and Technology**.

The main goal is simple:

> **To make useful academic resources easier to find, access, share, and preserve for students across different batches.**

---

# 🏫 Repository Structure

The repository follows a simple and consistent structure so that students from different batches can easily understand where everything belongs.

```text
SE-NED-Study-Material
│
├── Batch-2024
│   │
│   ├── Semester-1
│   ├── Semester-2
│   ├── ...

│
├── Batch-2025
│   │
│   ├── Semester-1
│   ├── Semester-2
│   └── ...
│
├── Batch-2026
│   │
│   ├── Semester-1
│   └── ...
│
└── README.md
```

Each batch should have its own folder.

Inside each batch folder, material should be organized semester by semester.

Inside each semester folder, resources should be further organized according to subjects or courses whenever possible.

### Recommended structure

```text
Batch-Year
│
├── Semester-1
│   ├── Subject-1
│   ├── Subject-2
│   ├── Subject-3
│   └── Past-Papers
│
├── Semester-2
│   ├── Subject-1
│   ├── Subject-2
│   └── ...
```

Please follow this structure when adding material so that the repository remains clean and easy to navigate.

# 🗂️ Contribution Guidelines

When contributing material, please follow the repository structure.

### 1. Follow the batch structure

Place resources under the correct batch.

```text
Batch-Year
```

### 2. Follow the semester structure

Inside the batch folder, organize material according to semester.

```text
Batch-Year
└── Semester-X
```

### 3. Organize by subject

Whenever possible, place resources inside the relevant subject or course folder.

```text
Batch-Year
└── Semester-X
    └── Subject-Name
```

### 4. Keep the repository organized

Please do not randomly upload files into the root directory or unrelated folders.

Following the existing structure keeps the repository useful for everyone.
